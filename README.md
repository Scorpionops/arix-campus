# ARIX Campus

**Artificial Reasoning Intelligence X**

An AI-powered Campus Assistant designed for educational institutions.

## Vision

To simplify academic, administrative, and placement activities using Artificial Intelligence.

## Features

- 🤖 AI Chat Assistant
- 👨‍🎓 Student Dashboard
- 👨‍🏫 Faculty Dashboard
- 💼 Placement Assistant
- 📄 Resume Builder
- 🎤 Mock Interview
- 📝 Question Paper Generator
- 📚 Notes Assistant

## Technology Stack

- React + TypeScript
- Tailwind CSS
- FastAPI
- PostgreSQL
- Gemini API
- Firebase Authentication
